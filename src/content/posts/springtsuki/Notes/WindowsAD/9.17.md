## 一、Windows Server Backups

这个服务不用多说，直接装好然后做一次全量备份即可，后续的更新均为增量备份。

## 二、演练过程

删除一个用户，而后使用 DRSM 进行恢复。

删除用户后，如果不想等复制，可以强制推送：repadmin /syncall。

而后进入 DSRM 使用 Backups 恢复数据，并进行授权还原。

```cmd
ntdsutil
activate instance ntds
authoritative restore
restore subtree "CN=Organization,DC=qy,DC=net"
quit
quit
```

最后重新进入 Server，强制推送后进行测试。即可完成。

## 三、纯命令行演示

如果 GUI 坏了，只有 CLI，要怎么办呢？这里给出示例好啦！

```cmd
# 在 DSRM 里看备份版本
wbadmin get versions

# 开始还原
wbadmin start systemstaterecovery -version:<你看到的版本标识符>
```
