# AD 的每日基本巡检

## 1. FSMO 角色日常维护

老样子，先复习一下日常如何查看 FSMO 角色吧！

```powershell
ntdsutil
roles
connections
connect to server <domain.com>
quit
select operation target
list roles for connected server
```

## 2. 每日检查复制状态

核心是 rapadmin 和 dcdiag，要熟练运用此命令与部分子命令

```powershell
repadmin /replsummary # 检查 AD 复制状态
dcdiag # 检查域控制器整体健康状况
```

### 2.1.3 dcdiag 巡检

```powershell
dcdiag /e /q /c         # /e 全林 /c 全套 /q 只报错,输出最节省
dcdiag /test:replications
dcdiag /test:connectivity
```

核心看有没有 PASS 以外的行。一般跑 dcdiag 全量会比较慢,巡检可直接 /e /c,或 先 /replsummary 再按需 dcdiag 更高效。

### 2.1.4 事件查看器常见的 Event_ID

```powershell
Event_ID：4740
类型：用户密码被锁定

TargetUserName：被锁定的账户
TargetDomainName：账户所在的计算机名
SubjectUserName：触发锁定事件的执行者
SubjectLogonId：登录会话ID
```

详细 ID 速查表：
| 事件ID | 名称 | 说明 | 关注度 |
| :--- | :--- | :--- | :--- |
| **4740** | 账户被锁定 | 触发锁定的核心事件。记录了谁被锁、锁定来源机器。 | ⭐⭐⭐ |
| **4625** | 登录失败 | 密码错误、账户过期、限制登录等失败的尝试。这是锁定前的“前兆”事件。 | ⭐⭐⭐ |
| **4624** | 登录成功 | 成功的登录记录。可用于追溯锁定时段内是否还有其他正常登录。 | ⭐⭐ |
| **4767** | 账户被解锁 | 管理员或系统解锁账户的事件。可配合4740追踪锁定-解锁的时间线。 | ⭐⭐ |
| **4648** | 使用显式凭据登录 | 尝试使用其他账户的凭据登录。可用于排查横向移动或凭证滥用。 | ⭐⭐ |
| **4771** | Kerberos 预认证失败 | 密码过期、时间不同步或账户被禁用的常见原因。 | ⭐⭐ |
| **4776** | 凭据验证失败 | 当域控无法验证一个账户的凭据时记录，常见于NTLM认证失败场景。 | ⭐⭐ |

关于高位端口，也可以在这个列表中看到。它指的是 AD 复制和 RPC 通信时使用的那一段端口范围，这在配置防火墙时经常会遇到。

当域控之间需要进行复制、身份验证或其他 RPC 通信时，它们会通过 TCP 135 端口建立连接，然后实际的数据传输会通过动态分配的高位端口进行。

在需要排查问题时，可以在域控上使用以下命令查看当前活动的 RPC 连接：

```powershell
netstat -an | findstr 49152
```

## 4. netsh trace 抓包

netsh trace 是 Windows 内置的网络诊断与跟踪工具。它能捕获网络数据包和系统事件，并生成详细的日志。

它最常用的场景就是抓包。核心流程是“开始捕获”和“停止捕获”两步：

### 4.1 开始捕获网络流量

```cmd
netsh trace start capture=yes
```

如果需要更精细的控制，可以加上一些常用参数：
```cmd
capture=yes # 开始捕获网络流量
tracefile=路径 # 指定生成的 .etl 文件的保存路径和名称
maxsize=数值 # 设置单个日志文件的最大大小（MB），超过会循环覆盖。
persistent=yes # 即使重启电脑，捕获任务也会在重启后继续运行。
```

### 4.2 停止捕获并生成报告

当问题复现后，在命令提示符中执行 netsh trace stop。系统会停止捕获，并开始合并和生成两个文件：

.etl 文件：原始数据文件。

.cab 文件：包含一个 HTML 格式的摘要报告和更详细的数据。

可以直接打开 .cab 文件中的 HTML 报告，可以快速了解网络活动的整体状况。.etl 文件可以用 netsh trace convert 命令转换为 CSV、XML 或文本格式，便于深入分析。
